# 🚦 SiteMigrationGuard MCP

Live website migration execution and SEO risk audit for agencies, developers and site owners.

## Why it exists

ChatGPT can explain migration best practices. SiteMigrationGuard crawls the live old and new sites, tests redirects, reads robots.txt and sitemap.xml, compares paths, and returns evidence-backed fixes before traffic is lost.

## Tools

- `migration.architect` — migration plan
- `site.crawl_live` — live crawl with status, titles, canonicals and internal links
- `redirects.check_live` — redirect chains, loops and broken destinations
- `sitemap.audit_live` — robots, sitemap and URL checks
- `migration.compare_live` — old/new path comparison
- `migration.report_live` — prioritized end-to-end live report
